---
title: "How a computer works"
description: "Follow a Cool Computers computer from creation through running a service and deletion."
---

A computer has one name for its whole lifetime. That name ties together the machine, its public address, and its inbox.

## Create

Create a computer from the website, CLI, or HTTP API. A computer named `bakery` receives these addresses:

- Public service: `bakery.cool.computer`
- Inbox: `bakery@mail.cool.computer`

## Work

Use the browser terminal or `cool enter bakery` for an interactive shell. Use `cool exec` for one command. Files, installed packages, databases, and system configuration live on the computer's writable disk.

## Publish

Each computer can run one configured HTTP service at its public address. Start and inspect that service with `cool service`, the HTTP API, or `runtime-env service` from inside the computer.

The public address waits up to 60 seconds for your service to send response headers, then returns `504`, before any Cloudflare `524` timeout. Answer within 60 seconds and do longer work in the background. Once headers arrive, streamed responses and WebSocket connections have no time limit.

## Keep working

Your computer stays running until you delete it. Leaving the terminal or closing the browser keeps the computer available. Background services and timers can continue while you are away. Requests to the public address reach the exposed HTTP port.

## Delete

Deleting a computer removes it from your account and gives up its name, address, inbox, and stored data. Delete it only when you no longer need that identity or its files.
