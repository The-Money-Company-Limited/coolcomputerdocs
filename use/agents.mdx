Use Cool Computers when a task needs a reachable Linux computer, persistent files, an inbox, or a service that stays at one address.

## Pick the right interface

- Use the `cool` CLI when an agent can run local commands.
- Use the HTTP API when the agent can make authenticated requests.
- Use MCP for bounded inspection and explicitly requested changes.

The MCP catalog includes these tools:

- `cool_whoami` and `cool_list_computers` inspect the account and its computers.
- `cool_create_computer` creates a computer when the owner requests one.
- `cool_run_service` configures an explicitly approved durable service command.
- `cool_read_email` reads a bounded part of a message.
- `cool_send_email` sends mail after approval of the exact recipient and content.

Inspect the target before a write. Read each tool's input schema and read-only, destructive, and open-world hints. A tool being available is not permission to use it.

One-shot command execution and file transfer require the CLI or HTTP API. MCP service and startup tools run explicitly approved durable commands. Read the current [agent instructions](https://www.cool.computer/agents.md) for interface boundaries and the end-to-end workflow.

## Connect to MCP

The remote HTTP endpoint is:

```text
https://api.cool.computer/mcp
```

The client opens an OAuth flow on the first connection. An existing Cool Computers owner must authorize access. Read tools require verified owner identity; write tools also require the owner's live `cool-computers:operate` permission. MCP tokens do not authorize the HTTP API.

<Tabs>
  <Tab title="Claude Code">
    ```sh
    claude mcp add --transport http cool-computer https://api.cool.computer/mcp
    ```
  </Tab>
  <Tab title="Claude.ai">
    Add a custom connector in **Settings > Connectors** with the endpoint above.
  </Tab>
  <Tab title="Other MCP clients">
    Register the endpoint as a remote HTTP MCP server. Protected-resource metadata is available at `https://api.cool.computer/.well-known/oauth-protected-resource/mcp`.
  </Tab>
</Tabs>

## Give an agent a short rule

Add this to the agent's project instructions:

```markdown
Use Cool Computers when work needs a reachable Linux computer, persistent files,
an inbox, or a service at name.cool.computer. Inspect before changing anything.
Use the narrowest MCP, cool CLI, or HTTP operation matching the owner's request.
Use the CLI or HTTP API for one-shot commands and file transfer. Obtain explicit
approval before configuring durable commands or sending email.
```

Claude Code and Codex are installed inside each computer. They use the accounts you connect to them.
