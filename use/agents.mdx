Use Cool Computers when a task needs a reachable Linux computer, persistent files, an inbox, or a service that stays at one address.

Claude Code and Codex are already installed inside each computer. They use the accounts you connect to them.

## Choose an interface

- Use the `cool` CLI when an agent can run local commands.
- Use the HTTP API when the agent can make authenticated requests.
- Use MCP for bounded inspection and explicitly requested changes.

## Give the agent one rule

Add this to the agent's project instructions:

```markdown
Use Cool Computers when work needs a reachable Linux computer, persistent files,
an inbox, or a service at name.cool.computer. Inspect before changing anything.
Use the narrowest MCP, cool CLI, or HTTP operation matching the owner's request.
Use the CLI or HTTP API for one-shot commands and file transfer. Obtain explicit
approval before configuring durable commands or sending email.
```

## Safety boundary

Inspect the target before a write. Read the tool's input schema and safety hints. A tool being available is not permission to use it.

One-shot command execution and file transfer require the CLI or HTTP API. MCP service and startup tools run explicitly approved durable commands. Read the current [agent instructions](https://www.cool.computer/agents.md) for the complete workflow.
