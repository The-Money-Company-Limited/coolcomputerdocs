Install the native `cool` command with Homebrew or a standalone installer. It does not require Node.js or Python.

## Homebrew

With [Homebrew](https://brew.sh) installed, run:

```sh
brew install the-money-company-limited/tap/cool
```

The official tap installs the native binary for macOS on Apple Silicon or Intel, or Linux on ARM64 or x64.

## Standalone macOS and Linux

```sh
curl -fsSL https://cool.computer/install.sh | sh
```

## Windows PowerShell

```powershell
(iwr -UseBasicParsing https://cool.computer/install.ps1).Content | iex
```

The installer adds `cool` to the current PowerShell session and your user `PATH`. Restart terminal apps that were already open before installation.

## Agent instructions

The standalone installers add CLI instructions to supported coding agents whose configuration directories already exist. Homebrew leaves those files unchanged. To add or refresh the instructions yourself:

```sh
cool agents install
```

To remove the CLI instructions:

```sh
cool agents remove
```

## Update

For Homebrew installations:

```sh
brew upgrade the-money-company-limited/tap/cool
```

`cool update` also directs Homebrew installations to this command.

For standalone installations, run `cool update` or rerun the installer:

## Remove

Before removing the CLI, run `cool agents remove` to remove instructions added by the standalone installer or by `cool agents install`.

For Homebrew installations:

```sh
brew uninstall cool
```

For standalone installations:

<Tabs>
  <Tab title="macOS and Linux">
    ```sh
    rm -f ~/.local/bin/cool
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    $installDir = "$env:LOCALAPPDATA\Programs\coolcomputer"
    Remove-Item -LiteralPath "$installDir\cool.exe" -Force
    $environmentKey = [Microsoft.Win32.Registry]::CurrentUser.OpenSubKey(
      "Environment",
      $true
    )
    $pathKind = $environmentKey.GetValueKind("Path")
    $userPath = [string]$environmentKey.GetValue(
      "Path",
      "",
      [Microsoft.Win32.RegistryValueOptions]::DoNotExpandEnvironmentNames
    )
    $cleanPath = (($userPath -split ";") | Where-Object {
      [Environment]::ExpandEnvironmentVariables($_) -ne $installDir
    }) -join ";"
    $environmentKey.SetValue("Path", $cleanPath, $pathKind)
    $environmentKey.Dispose()
    ```

    Restart terminal apps that were open before removal.
  </Tab>
</Tabs>
