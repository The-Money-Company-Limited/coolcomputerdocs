Create a computer named `bakery`. Pick another available name if you prefer.

Sign up or sign in with your email address. New and existing accounts use an email verification code.

## Create the computer

<Tabs>
  <Tab title="Website">
    1. Open the [Cool Computers dashboard](https://www.cool.computer/app).
    2. Sign up or sign in with your email address.
    3. Create a computer named `bakery`.

    The computer appears in your dashboard.
  </Tab>
  <Tab title="CLI">
    Install the CLI.

    macOS and Linux:

    ```sh
    curl -fsSL https://cool.computer/install.sh | sh
    ```

    Windows PowerShell:

    ```powershell
    (iwr -UseBasicParsing https://cool.computer/install.ps1).Content | iex
    ```

    `cool login` sends a code to the email address you provide and signs you up or in. Agents must [ask the owner before sending it](/api-reference/authentication).

    ```sh
    cool login --email owner@example.com
    ```

    Create the computer and enter its terminal:

    ```sh
    cool create bakery
    ```

    In an interactive terminal, creation opens the computer's shell. Run `exit` to return to your local terminal. Use `cool enter bakery` to reconnect later. With `--json` or redirected input or output, creation returns without entering the computer.
  </Tab>
</Tabs>

Your computer keeps the public address `bakery.cool.computer` and inbox `bakery@mail.cool.computer` until you delete it.
