This example creates a computer named `bakery`. Pick another available name if you prefer.

You need an existing Cool Computers account. New account creation is temporarily paused; new owners can [join the waitlist](https://www.cool.computer/#waitlist).

## From the website

1. Open the [Cool Computers dashboard](https://www.cool.computer/app).
2. Sign in to your existing account.
3. Create a computer with an available name.

The computer appears in your dashboard. Its public address is `bakery.cool.computer`. Its inbox is `bakery@mail.cool.computer`.

## From a terminal

Install the CLI on macOS or Linux:

```sh
curl -fsSL https://cool.computer/install.sh | sh
```

If you are already signed in, skip this step. Otherwise, replace the email with your existing account's address. This sends a sign-in code; enter the code when prompted. Agents must [ask the owner before sending the email](/api-reference/authentication).

```sh
cool login --email owner@example.com
```

After sign-in completes, create the computer and enter its terminal:

```sh
cool create bakery
cool enter bakery
```

Run `exit` to leave the computer's terminal before running more local `cool` commands.

`cool create bakery --blank` creates the computer without starter files. Run `cool list` to see the computers in your account.

## Publish a service

From your local terminal, run one service at port 3000:

```sh
cool service run bakery --port 3000 -- python3 -m http.server 3000
```

Open `https://bakery.cool.computer`. The same address remains attached to the computer when it sleeps and wakes.
