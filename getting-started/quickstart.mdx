Create a computer named `bakery`. Pick another available name if you prefer.

You need an existing Cool Computers account. New account creation is temporarily paused; new owners can [join the waitlist](https://www.cool.computer/#waitlist).

## Create the computer

<Tabs>
  <Tab title="Website">
    1. Open the [Cool Computers dashboard](https://www.cool.computer/app).
    2. Sign in to your existing account.
    3. Create a computer named `bakery`.

    The computer appears in your dashboard.
  </Tab>
  <Tab title="CLI">
    Install the CLI.

    macOS and Linux:

    ```sh
    curl -fsSL https://cool.computer/install.sh | sh
    ```

    Windows PowerShell:

    ```powershell
    (iwr -UseBasicParsing https://cool.computer/install.ps1).Content | iex
    ```

    Sign in with your existing account. `cool login` sends a code to the email address you provide. Agents must [ask the owner before sending it](/api-reference/authentication).

    ```sh
    cool login --email owner@example.com
    ```

    Create the computer and enter its terminal:

    ```sh
    cool create bakery
    cool enter bakery
    ```

    Run `exit` to return to your local terminal.
  </Tab>
</Tabs>

Your computer keeps the public address `bakery.cool.computer` and inbox `bakery@mail.cool.computer` while it sleeps and wakes.
