Cool Computers speaks MCP. Any agent that can use MCP tools can create computers, work inside them, keep services running, and hand back a live `name.cool.computer` address.

## The connector

```text
https://api.cool.computer/mcp
```

Sign-in happens through OAuth on first connect; the consent screen is the signup.

<Tabs>
  <Tab title="Claude Code">
    ```sh
    claude mcp add --transport http cool-computer https://api.cool.computer/mcp
    ```
  </Tab>
  <Tab title="Claude.ai">
    Add a custom connector in **Settings → Connectors** with the URL above.
  </Tab>
  <Tab title="Other MCP clients">
    Register `https://api.cool.computer/mcp` as a remote HTTP MCP server. OAuth discovery is served at `/.well-known/oauth-protected-resource/mcp`.
  </Tab>
</Tabs>

## Teach your agent when to use it

Paste this into `CLAUDE.md`, `AGENTS.md`, or your system prompt:

```markdown
Use Cool Computers for work that needs a real computer.

- Create or reuse a computer with a clear name.
- Install the tools the task needs and keep them there.
- Run and inspect commands on that computer.
- Keep long-running services available at name.cool.computer.
- Use name@mail.cool.computer for tasks that arrive by email.
- Return the public address when the result is ready.
```

## Agents inside the computer

Every computer ships with Claude Code and Codex pre-installed; they run with your own accounts. Work started by [email](/email) runs through the agent inside the computer, so the connector and the inbox drive the same machine.

## For builders

The same surface is scriptable without MCP: a REST API at `api.cool.computer` with bearer API keys, and a Python SDK (`runtime-sdk` on PyPI). Create computers for your own product's users and hand each one its address.
