Every path below ends the same way: a persistent Linux computer at `name.cool.computer` with `name@mail.cool.computer` as its inbox and coding agents pre-installed.

## From the browser

1. Go to [cool.computer](https://www.cool.computer), type a name into the address bar on the page, and create your computer.
2. Sign in with your email and the six-digit code it sends you.
3. Your computer boots with a starter service already published at `name.cool.computer`.

## From the terminal

Install the `cool` CLI:

```sh
curl -fsSL https://cool.computer/install.sh | sh
```

Then create and enter a computer:

```sh
cool login
cool create bakery
cool enter bakery
```

`cool create --blank` skips the starter content. `cool list` shows everything you have. See [Install](https://www.cool.computer/install) for package-manager installs and Windows.

## With SSH, no install

```sh
ssh cool.computer
```

OpenSSH proves your key, Cool Computers asks for your email and a six-digit code once, and the account dashboard opens in your terminal. See [Connect with SSH](https://www.cool.computer/ssh) for host-key verification.

## Then reach it

- Visit `name.cool.computer` — the first request wakes a sleeping computer.
- [Email it a task](/email) at `name@mail.cool.computer`.
- [Connect your agent](/agents) and let it do the work.
