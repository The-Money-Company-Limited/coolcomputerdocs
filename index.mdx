Cool Computers gives you a Linux computer with a name. If you call it `bakery`, its public address is `bakery.cool.computer` and its inbox is `bakery@mail.cool.computer`.

Install the software you need and come back later. The computer keeps its writable disk, name, address, inbox, and configured service while it sleeps. A request to its public address can wake it and reach that service.

## Pick an interface

- Use the website when you want to create a computer and see it in your account.
- Use the `cool` CLI when you work from a terminal.
- Run `ssh cool.computer` to open the account dashboard without installing the CLI.
- Use HTTP when another program needs to create or operate a computer.
- Use the MCP preview to inspect the signed-in account and list its computers.
