OpenClaw keeps one Cool Computers sign-in for its operator, whichever way you connect it. Everyone who chats with that OpenClaw works on the same Cool Computers account.

## Paste this

Send this sentence to OpenClaw wherever you chat with it:

```text wrap
Read cool.computer/setup.md and make me a welcome page
```

OpenClaw installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

To add the MCP server, run this where OpenClaw runs:

```sh
openclaw mcp set cool-computers '{"url":"https://api.cool.computer/mcp","transport":"streamable-http","auth":"oauth"}' && openclaw mcp login cool-computers
```

`openclaw mcp login` prints a link. Open it and sign in, or sign up.

## Check it works

Ask OpenClaw:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, run `openclaw mcp doctor cool-computers --probe` to check the connection.
