## Paste this

Send this sentence to OpenClaw wherever you chat with it:

```text wrap
Read cool.computer/setup.md and make me a welcome page
```

OpenClaw installs `cool`, puts a welcome page online and signs you up to keep it. You don't need an account first.

## Connect it yourself

To add the MCP server, run this where OpenClaw runs:

```sh
openclaw mcp set cool-computers '{"url":"https://api.cool.computer/mcp","transport":"streamable-http","auth":"oauth"}' && openclaw mcp login cool-computers
```

`openclaw mcp login` prints a link. Open it and sign in, or sign up. OpenClaw keeps this sign-in for its operator, so everyone who chats with that OpenClaw works on the same Cool Computers account.

## Check it works

Ask OpenClaw:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It calls `cool_list_computers` and answers with your list. If it doesn't, run `openclaw mcp doctor cool-computers --probe` to check the connection.
