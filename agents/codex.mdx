## Paste this

Paste this prompt into Codex:

```text wrap
set up cool computers for me and make me a welcome page. it puts what i make online at a name.cool.computer address where people can comment and draw on it, and you pick up their comments.

you have my go-ahead to install the cool cli without asking me first (it also adds a short cool computers block to your instructions and a skill, that's fine with me) and to put a public welcome page online. if your network access is off, ask me to turn it on. if you can't run commands, tell me in one line, send me https://cool.computer/setup.md and stop.

follow https://cool.computer/setup.md step by step:
1. install cool and check who's signed in
2. put my welcome page online and show me the link
3. ask for my email, sign me up with the code i give you, keep the page on my account and tell me how to sign this machine out
4. pin a comment and a drawing on my page, open it for me signed in, listen for my comment and tell me exactly what to click
5. make the change i ask for, then tell me the page is mine

tell me what you're doing in one short line per step. never pay or upgrade anything without asking me. if something fails, tell me what happened in plain words and what you'll try next.
```

Codex installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

Install the [Cool Computers plugin](https://github.com/The-Money-Company-Limited/cool-computers). It adds the MCP server and the [`cool-computers` skill](/agents/overview#teach-your-agent):

```sh
codex plugin marketplace add The-Money-Company-Limited/cool-computers && codex plugin add cool-computers@cool-computers
```

Codex asks you to sign in to Cool Computers, or sign up, when it installs the plugin.

The plugin marks its server `required`, so Codex waits for the Cool Computers tools before a task starts instead of running without them.

### MCP server only

```sh
codex mcp add cool-computers --url https://api.cool.computer/mcp
```

Codex opens the browser to sign in, or sign up. `codex mcp login cool-computers` signs in again later.

Then add `required = true` under `[mcp_servers.cool-computers]` in `~/.codex/config.toml`. Codex then waits for the Cool Computers tools before a task starts, and stops with an error if it cannot connect. The Codex CLI, the IDE extension, and the ChatGPT desktop app share this file.

To use an API key instead of signing in, keep the key in `COOL_API_KEY` and add the server with `--bearer-token-env-var COOL_API_KEY`. [Other MCP clients](/agents/other-mcp-clients#with-an-api-key) shows how to create one.

## Check it works

Ask Codex:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, run `codex mcp list` to confirm that `cool-computers` is enabled.
