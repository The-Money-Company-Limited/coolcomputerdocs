## Paste this

Paste this prompt into Hermes:

```text wrap
set up cool computers for me: follow https://cool.computer/setup.md and build me an artifact about the last thing i was working on, and annotate and draw on it once i'm signed up
```

Hermes installs `cool` and puts an artifact about your last work online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

To add the MCP server:

```sh
hermes mcp add cool-computers --url https://api.cool.computer/mcp --auth oauth
```

Hermes opens the sign-in the first time it connects. Sign in, or sign up. `hermes mcp login cool-computers` signs in again.

## Check it works

Ask Hermes:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, run `hermes mcp test cool-computers` to test the connection.
