## Paste this

Paste this prompt into Cursor's agent:

```text wrap
set up cool computers for me and make me a welcome page. it puts what i make online at a name.cool.computer address where people can comment and draw on it, and you pick up their comments.

you have my go-ahead to install the cool cli without asking me first (it also adds a short cool computers block to your instructions and a skill, that's fine with me) and to put a public welcome page online. if your network access is off, ask me to turn it on. if you can't run commands, tell me in one line, send me https://cool.computer/setup.md and stop.

follow https://cool.computer/setup.md step by step:
1. install cool and check who's signed in
2. put my welcome page online and show me the link
3. ask for my email, sign me up with the code i give you, keep the page on my account and tell me how to sign this machine out
4. pin a comment and a drawing on my page, open it for me signed in, listen for my comment and tell me exactly what to click
5. make the change i ask for, then tell me the page is mine

tell me what you're doing in one short line per step. never pay or upgrade anything without asking me. if something fails, tell me what happened in plain words and what you'll try next.
```

Cursor installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

<Card title="Add to Cursor" icon="/images/agents/cursor.svg" href="https://cursor.com/en/install-mcp?name=cool-computers&config=eyJ1cmwiOiJodHRwczovL2FwaS5jb29sLmNvbXB1dGVyL21jcCJ9">
  Cursor asks you to confirm the `cool-computers` server, then signs you in, or up.
</Card>

Or add the server yourself, to `~/.cursor/mcp.json` for every project or to `.cursor/mcp.json` in one project:

```json
{
  "mcpServers": {
    "cool-computers": {
      "url": "https://api.cool.computer/mcp"
    }
  }
}
```

Cursor signs in to Cool Computers with OAuth the first time it connects.

To use an API key instead of signing in, keep the key in `COOL_API_KEY` and send it as a bearer token. [Other MCP clients](/agents/other-mcp-clients#with-an-api-key) shows how to create one.

```json
{
  "mcpServers": {
    "cool-computers": {
      "url": "https://api.cool.computer/mcp",
      "headers": {
        "Authorization": "Bearer ${env:COOL_API_KEY}"
      }
    }
  }
}
```

To add the `cool-computers` skill as well, see [Teach your agent](/agents/overview#teach-your-agent).

## Check it works

Ask Cursor's agent:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, check `cool-computers` under MCP in Cursor's settings.
