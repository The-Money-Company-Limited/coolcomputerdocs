## Paste this

Paste this prompt into Cursor's agent:

```text wrap
set up cool computers for me: follow https://cool.computer/setup.md and make me a welcome page
```

<Card title="Open Cursor" icon="/images/agents/cursor.svg" href="https://cursor.com/link/prompt?text=set%20up%20cool%20computers%20for%20me%3A%20follow%20https%3A%2F%2Fcool.computer%2Fsetup.md%20and%20make%20me%20a%20welcome%20page">
  Opens Cursor with the prompt typed in. Cursor asks you to confirm before it runs.
</Card>

Cursor installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

Install the Cool Computers plugin from the Cursor Marketplace. It adds the MCP server and the [`cool-computers` skill](/agents/overview#teach-your-agent).

<Card title="Add to Cursor" icon="/images/agents/cursor.svg" href="https://cursor.com/marketplace/cool-computers">
  Opens Cool Computers in the Cursor Marketplace.
</Card>

Or type this in Cursor's agent:

```text
/add-plugin cool-computers
```

You can also open **Customize** in Cursor's sidebar, find Cool Computers and choose **Install**. Cursor signs in to Cool Computers with OAuth the first time it connects.

<AccordionGroup>
  <Accordion title="Add it by hand">
    <Card title="Add the MCP server to Cursor" icon="/images/agents/cursor.svg" href="https://cursor.com/en/install-mcp?name=cool-computers&config=eyJ1cmwiOiJodHRwczovL2FwaS5jb29sLmNvbXB1dGVyL21jcCJ9">
      Cursor asks you to confirm the `cool-computers` server, then signs you in, or up.
    </Card>

    Or add the server yourself, to `~/.cursor/mcp.json` for every project or to `.cursor/mcp.json` in one project:

    ```json
    {
      "mcpServers": {
        "cool-computers": {
          "url": "https://api.cool.computer/mcp"
        }
      }
    }
    ```

    To use an API key instead of signing in, keep the key in `COOL_API_KEY` and send it as a bearer token. [Other MCP clients](/agents/other-mcp-clients#with-an-api-key) shows how to create one.

    ```json
    {
      "mcpServers": {
        "cool-computers": {
          "url": "https://api.cool.computer/mcp",
          "headers": {
            "Authorization": "Bearer ${env:COOL_API_KEY}"
          }
        }
      }
    }
    ```

    To add the `cool-computers` skill as well, see [Teach your agent](/agents/overview#teach-your-agent).
  </Accordion>
</AccordionGroup>

## Check it works

Ask Cursor's agent:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If it doesn't, check `cool-computers` under MCP in Cursor's settings.
