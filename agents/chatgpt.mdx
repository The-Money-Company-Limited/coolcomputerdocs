## Add the plugin

1. Open [chatgpt.com/plugins](https://chatgpt.com/plugins). In the ChatGPT desktop app, open **Plugins**.
2. Find Cool Computers and choose **+**.
3. Choose **Connect**, and sign in to Cool Computers, or sign up.
4. Start a new chat.

You can also use the installed plugin in Codex in the ChatGPT desktop app. See [Codex](/agents/codex).

<AccordionGroup>
  <Accordion title="Add it by hand">
    1. Open [chatgpt.com/plugins](https://chatgpt.com/plugins).
    2. Choose **+**, then **Add custom MCP server**.
    3. Name it Cool Computers and enter this server URL:

       ```text
       https://api.cool.computer/mcp
       ```

    4. Choose **OAuth**. Read the warning, then choose **I understand and want to continue**.
    5. Choose **Create as a plugin**.
    6. Choose **Install**, then **Connect**, and sign in to Cool Computers, or sign up.
  </Accordion>
</AccordionGroup>

## Paste this

In a new chat, ask:

```text wrap
make me a welcome page and put it on cool.computer
```

<Card title="Open ChatGPT" icon="/images/agents/openai.svg" href="https://chatgpt.com/?q=make%20me%20a%20welcome%20page%20and%20put%20it%20on%20cool.computer">
  Opens a new chat in ChatGPT with the request.
</Card>

ChatGPT publishes the page with the plugin and gives you its link. If ChatGPT doesn't use Cool Computers on its own, type **@** in the message box, choose Cool Computers, and ask again.

## Check it works

Ask ChatGPT:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If it doesn't, check that Cool Computers is added and connected at [chatgpt.com/plugins](https://chatgpt.com/plugins), then type **@**, choose Cool Computers, and ask again.
