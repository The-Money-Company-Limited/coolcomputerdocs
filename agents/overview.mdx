Your agent makes something, and Cool Computers puts it online at `name.cool.computer`. Pick the way in that matches your agent. Each page has three parts: a sentence to paste, a way to connect it yourself, and a check that it works.

## Paste this

An agent that runs commands needs one sentence:

```text wrap
Read cool.computer/setup.md and make me a welcome page
```

The agent reads the [setup guide](https://cool.computer/setup.md), installs `cool`, puts a welcome page online and signs you up to keep it. You don't need an account first.

Claude and ChatGPT don't run commands. Add Cool Computers to them as a connector, then ask:

```text wrap
make me a welcome page and put it on cool.computer
```

## The MCP server

Every client connects to the same server:

```text
https://api.cool.computer/mcp
```

Name it `cool-computers`. It speaks Streamable HTTP and signs in with OAuth, as its [protected resource metadata](https://api.cool.computer/.well-known/oauth-protected-resource/mcp) describes. The sign-in also lets you create an account, so a new user can sign up in the middle of connecting.

The server's `cool_*` tools read your sites, computers, files, comments, and email. Its write tools publish a site (`cool_publish`), write files (`cool_write_files`), run a command on a computer with a VM (`cool_exec`), answer comments, and send email. Read tools need your sign-in. Write tools also check that your account holds the `cool-computers:operate` permission at the moment of the call. An MCP sign-in does not work for the [HTTP API](/api-reference/overview).

A tool being available is not permission to use it. Ask your agent for the change you want, and approve email and long-running programs yourself.

## Teach your agent

The [CLI installer](/agents/cli#agent-instructions) runs `cool agents install`, which writes a short block of instructions and the `cool-computers` skill for Claude Code, Codex, Pi, and OpenCode. The Claude Code and Codex plugins include the same skill. For everything after setup, your agent reads [cool.computer/agents.md](https://cool.computer/agents.md) or runs `cool skill`.
