## Paste this

Paste this prompt into Pi:

```text wrap
set up cool computers for me: follow https://cool.computer/setup.md and make me a welcome page
```

Pi installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

To add the MCP server, with Pi 1.0 or later:

```sh
pi mcp add cool-computers --url https://api.cool.computer/mcp && pi mcp login cool-computers
```

`pi mcp login` opens the browser to sign in, or sign up. In a Pi session that is already open, run `/reload` to load the server.

### The skill and the comments extension

[`cool agents install`](/agents/cli#agent-instructions) gives Pi the `cool-computers` skill and the extension `~/.pi/agent/extensions/cool-computers.ts`. The standalone `cool` installer runs it for you; after a Homebrew install, run it yourself.

The extension's one tool, `cool_comments_watch`, listens on a site Pi published. When the site's owner sends Pi comments from the page, it starts a Pi turn. It listens until that Pi session ends, so call it again for each site after `/new`, `/resume`, or a reload.

## Check it works

Ask Pi:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, run `pi mcp list` to see the server's state and errors.
