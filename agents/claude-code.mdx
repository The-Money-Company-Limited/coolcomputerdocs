## Paste this

Paste this prompt into Claude Code:

```text wrap
set up cool computers for me and make me a welcome page. it puts what i make online at a name.cool.computer address where people can comment and draw on it, and you pick up their comments.

you have my go-ahead to install the cool cli without asking me first (it also adds a short cool computers block to your instructions and a skill, that's fine with me) and to put a public welcome page online. if your network access is off, ask me to turn it on. if you can't run commands, tell me in one line, send me https://cool.computer/setup.md and stop.

follow https://cool.computer/setup.md step by step:
1. install cool and check who's signed in
2. put my welcome page online and show me the link
3. ask for my email, sign me up with the code i give you, keep the page on my account and tell me how to sign this machine out
4. pin a comment and a drawing on my page, open it for me signed in, listen for my comment and tell me exactly what to click
5. make the change i ask for, then tell me the page is mine

tell me what you're doing in one short line per step. never pay or upgrade anything without asking me. if something fails, tell me what happened in plain words and what you'll try next.
```

Claude Code installs `cool` and puts a welcome page online. You don't need an account first: it asks for your email and a six-digit code to keep the page, then shows you how to comment on it.

## Connect it yourself

Install the [Cool Computers plugin](https://claude.com/marketplace/plugins/cool-computers) from Anthropic's official marketplace. It adds the MCP server and the [`cool-computers` skill](/agents/overview#teach-your-agent). In Claude Code, run:

```text
/plugin install cool-computers@claude-plugins-official
```

Or run `/plugin`, search for Cool Computers on the **Discover** tab, and install it. From your shell:

```sh
claude plugin install cool-computers@claude-plugins-official
```

Then run `/mcp` in Claude Code, choose `plugin:cool-computers:cool-computers`, and sign in, or sign up, in the browser that opens.

<AccordionGroup>
  <Accordion title="Add it by hand">
    Install the plugin from its [GitHub marketplace](https://github.com/The-Money-Company-Limited/cool-computers) instead. This needs Claude Code 2.1.292 or later:

    ```sh
    claude plugin install cool-computers --marketplace The-Money-Company-Limited/cool-computers
    ```
  </Accordion>
</AccordionGroup>

### MCP server only

To add the server without the skill, for every project:

```sh
claude mcp add --scope user --transport http cool-computers https://api.cool.computer/mcp
```

Run `/mcp`, choose `cool-computers`, and sign in.

To use an API key instead of signing in, keep the key in `COOL_API_KEY` and send it as a bearer token. [Other MCP clients](/agents/other-mcp-clients#with-an-api-key) shows how to create one.

```sh
claude mcp add --scope user --transport http cool-computers https://api.cool.computer/mcp --header "Authorization: Bearer $COOL_API_KEY"
```

## Check it works

Ask Claude Code:

```text
List my Cool Computers sites and computers. Don't change anything.
```

It answers with your list. If you added the MCP server and it doesn't, run `/mcp` in Claude Code to see the server's state.
