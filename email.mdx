Every computer has a stable inbox at `name@mail.cool.computer`. It stays with the computer through sleep, cold storage, and restore.

## Send a task

Write to your computer the way you would brief a person:

```text
To: bakery@mail.cool.computer
Subject: Menu update

Update the menu with today's sourdough and publish it.
```

The agent inside the computer treats the email body as the task, does the work in `/home/runtime`, and replies to the thread with the result:

```text
Done. Live at bakery.cool.computer.
```

Reply to the same thread to keep going. The whole loop stays attached to one identity: `bakery@mail.cool.computer` receives the work, `bakery.cool.computer` shows it.

## Who can start work

Only mail from your verified account address starts a task. Cool Computers independently verifies each message's DKIM signature and envelope before anything runs. Mail from anyone else lands in the computer's inbox for you to read, and runs nothing.

## How tasks run

- Tasks run one at a time, in the order the mail arrived.
- Each run is capped at 60 minutes.
- Every inbound email gets a durable accepted-or-rejected decision you can inspect.

Follow a run from the terminal:

```sh
cool goal list bakery
cool goal watch
```

`cool goal watch` attaches to the newest active task, or waits for the next one. `cool goal retry <goal>` re-runs a failed task.

## From inside the computer

The computer can read and send its own mail:

```sh
runtime-env email address
runtime-env email inbox --json
runtime-env email send --to you@example.com --subject "Report" --text "Done."
```
